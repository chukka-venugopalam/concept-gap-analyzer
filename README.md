# CIP (Concept Intelligence Platform)

CIP is a DSA diagnostic tool for software engineering interview preparation. It analyzes a user's explanation of a DSA topic and produces a precise Understanding Profile showing exactly what they know, what is weak, what is missing, and any misconceptions.

## Repository Structure

- `apps/web`: Next.js 14 frontend application
- `apps/api`: FastAPI backend application
- `database/migrations`: PostgreSQL database migration scripts
- `packages/shared`: Shared TypeScript definitions and constants
- `docs/`: Technical documentation
- `scripts/`: Utility shell scripts
